# 美术重构 v2 · 交付说明

## 一句话

这次不是“在原来的岛上再摆几件装饰”，而是重做了**空间、光、材质、界面**四层视觉框架：
把“平盘上的低模示意图”改成“有高差、有动线、有主角、可截图收藏的绘本微缩景观”。

## 先回应“框架没变”的问题

原版的问题不是模型不够多，而是四个底层判断错了：

1. **空间是平的**——岛是一个圆盘，所有东西铺在 y=0，读者一眼就把它当棋盘。
2. **光是均匀的**——太阳几乎在头顶、地面又盖着一层不接收阴影的草，画面没有方向与体积。
3. **轮廓是几何的**——正圆海岸、纯圆柱岩壁、纯色积木，缺少“手作模型”的边缘信息。
4. **界面是 SaaS 的**——白色药丸卡片和场景毫无材质关系，像把后台面板盖在游戏上。

v2 对应四刀：

| 层 | 改法 | 直接结果 |
| --- | --- | --- |
| 空间 | 后村缓坡抬升 0.98；四条石径串联农田—广场—住宅—林缘；风车/温室/磨坊小屋形成焦点 | 岛有剖面、有动线、有主次 |
| 光 | 左前低角度暖阳 + 冷天光 + 正面暖补光；草层接收阴影；2048 阴影；接触阴影 | 长投影、暖亮面、冷暗部 |
| 材质 | 岩壁改为 14 圈地层 + 苔痕 + 草皮翻边；草/花/灌木三层密度；深度描边后处理 | 轮廓破圆、地表有高频细节、像插画 |
| 叙事 | 风车、热气球、炊烟、鸡群、绵羊、蜂箱、晾衣绳、锦鲤、萤火虫、路灯光晕 | 截图里有“正在发生的事” |
| 界面 | 暖纸、墨绿、珊瑚三色；木牌按钮、纸页卡片、手账角标 | UI 与场景同一套材质语言 |

## 客观变化（同一机位、正午）

对岛体区域（不含 UI）做像素统计：

| 指标 | 重构前 | 重构后 | 变化 |
| --- | --- | --- | --- |
| 饱和度 P90 | 0.491 | 0.737 | **+50%**（强调色真正进入画面） |
| 亮度标准差 | 0.157 | 0.228 | **+45%**（明暗层次） |
| 边缘密度 | 0.105 | 0.165 | **+57%**（可读细节） |
| 暗部 P5 亮度 | 0.33 | 0.21 | 暗部更沉，主体更立体 |

> 指标不是审美本身，但能证明“不是只换了几个颜色”：画面的信息量、对比与色彩节拍都发生了变化。
> 基线图：`snapshot/cloudlet-art-v13-before.png`；对照图：`snapshot/cloudlet-art-v13-before-after.png`。

## 改动文件

- `src/render/meshes/terrain.ts`：有机海岸线、14 圈地层岩壁、草皮翻边、坡地高度场、野花/草叶
- `src/render/meshes/landmarks.ts`：石径系统、上层台地（备用）、风车
- `src/render/meshes/props.ts`：草垛、蜂箱、鸡、晾衣绳、温室、热气球、绵羊
- `src/render/meshes/structures.ts`：圆岛住宅放大 14%
- `src/render/scene.ts`：太阳/天光/补光、天空 shader、深度描边、调色、竖屏自动取景
- `src/render/backdrop.ts`：柔边云海 Sprite、鸟群、星空
- `src/render/world.ts`：石径网络、缓坡住宅、风车、叙事道具、接触阴影、炊烟、灯光光晕、萤火虫
- `src/render/grass.ts`：草接收阴影、实例化野花
- `src/render/palette.ts`：草/土/岩/水的新色板与光比
- `src/styles/main.css`、`src/main.ts`：手账 UI、品牌角标、移动端适配

## 还可以继续做的

- 方岛（网格建造模式）的岩壁与地表仍是旧语言，可复用圆形岛的地层/植被系统。
- 玩家实际建满建筑后的构图需要再做一轮“高密度压力测试”。
- 若要做真正的“季节变体”，可让树冠/花田/草色按季节整批换色，而不是只换草色。
