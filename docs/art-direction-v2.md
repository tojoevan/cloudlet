# 《云上小镇》美术重构方向 v2

> 目标不是“再加一点装饰”，而是把画面从**程序化低模示意图**推进到**可被截图收藏的绘本式微缩景观**。
> 玩法、数值、存档、交互路径保持不动；只重做视觉语言、构图、光照、材质与 UI。

## 一、线上对标（为什么是这几种语言）

| 参考 | 借什么 | 不借什么 |
| --- | --- | --- |
| [Dorfromantik](https://80.lv/articles/how-dorfromantik-expands-its-cozy-world-through-minimalist-design) | 低饱和但明确的色块、顶点色渐变、模块化地形边缘 | 六边形棋盘规则 |
| [Tiny Glade](https://www.youtube.com/watch?v=jusWW2pPnA0) | 草叶/花的**高频密度**、柔光、城堡剪影 | 写实材质与自由建造 |
| [Islanders](https://a327ex.com/logs/lookdev) | 极干净的“一个主色 + 一个辅色 + 一个强调色” | 无地表细节的极简 |

| [Low Poly Floating Island / ArtStation](https://www.artstation.com/artwork/5WBVZW) | 浮岛的**岩层切面**与“盆景式”构图 | 写实 PBR 贴图 |
| [Behance Low Poly Floating Island](https://www.behance.net/gallery/34244977/Low-Poly-Floating-Island) | 岛体轮廓的破圆、草皮翻边 | 纯展示、无生活痕迹 |

**结论**：保留 low-poly 的程序化优势，但必须补上四件当前缺的东西——
**轮廓破圆、光照方向、环境密度、叙事焦点**。

## 二、新的美术主张：云端绘本盆景

一句话：**一座被晨光擦亮的、有石径和风车的空中村落。**

- **形**：岛缘不再是完美圆盘，改成有凹凸的草甸边缘；岩壁分三层，草皮有翻边。
- **光**：左上暖阳 + 冷色天光；投影要看得见，暗部要偏青，亮部要偏蜜。
- **色**：草绿是主色，暖沙/珊瑚是辅色，矢车菊蓝是强调色；其余颜色向天空靠。
- **密**：岛缘一圈高草与花，林缘成簇，农田有围栏与稻草人，广场有人坐过的痕迹。
- **焦**：左前方风车 + 中央池塘广场 + 右侧树林，三点构成三角形视觉路径。
- **动**：风车叶片、炊烟、鸟群、花瓣/落叶、水波。让静态截图也有“正在发生”的感觉。

## 三、构图规则

1. **三分法**：风车在左下三分之一，池塘广场在中心偏下，树林在右侧三分之一。
2. **视觉引导**：一条石径从农田穿过广场，接到住宅；视线自然绕岛一周。
3. **前景/中景/远景**：前景枝叶遮幅 → 中景岛体 → 远景浮岛与云海。
4. **留白**：天空至少占 35%，岛体不顶满；UI 只压四角，不吃掉中心。
5. **剪影优先**：缩到 25% 大小仍能认出风车、屋顶、树冠、池塘。

## 四、可量化的验收维度（各 20 分）

| 维度 | 观察点 | 通过线 |
| --- | --- | --- |
| 构图 | 主次焦点、三分、留白、视线路径 | 16 |
| 色彩 | 主/辅/强调关系、冷暖对比、饱和度纪律 | 16 |
| 光照 | 投影方向一致、暗部不死黑、高光不糊 | 15 |
| 密度 | 每 100×100px 有可读细节，但不噪 | 15 |
| 叙事 | 能读出“有人住、有农事、有路” | 15 |
| UI | 与场景同一套材质语言，层级清晰 | 15 |

> 评分只看**同一机位、同一时刻**的截图；重构前基线见 `snapshot/cloudlet-day-before.png`。

## 五、实现边界

- 不引入外部贴图/模型，全部继续程序化生成。
- 不改 `core/` 的玩法逻辑与存档结构。
- 新增装饰不注册为可点击对象，不改变建造/收获判定。
- 低画质档保留关闭阴影/后处理的降级路径。
