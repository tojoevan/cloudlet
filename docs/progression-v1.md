# 进程实验 v1：云海拓荒

## 这次试的是什么

不是继续加建筑，也不是把房子往高里叠，而是验证一个更根本的问题：

> **有限的主岛，能不能通过“横向接新岛”持续长出新空间，同时不破坏坡屋顶村落的画风？**

答案是：可以，而且比纵向生长更顺。

## 已落地的东西

### 1. 主岛 + 两座可锚定小岛

- 云上町两侧各有一座拓荒小岛：**三叶岛**（右）、**风铃岛**（左）。
- 未锚定时：小岛以偏灰的草地 + 4 个白色田块轮廓出现，玩家一眼看到“这里还能加 4 块田”。
- 锚定后：亮色草地、树木、旗帜、绳桥接上主岛，4 块田变成可种植的真实田块。

**容量变化：16 → 20 → 24 块田。**
不是换皮，`state.plots` 真的追加，存档、离线、收获、种植、点击都走原有逻辑。

### 2. 三步拓荒手账

不新增任务存档，直接从现有统计推导，老档也能立刻用：

1. 累计收获 5 次
2. 完成 2 笔订单
3. 达到 Lv 3

完成后才能在“建造 → 云海拓荒”里花 2,000 金币锚定三叶岛；风铃岛还要求繁荣度 30 + 4,500 金币。

### 3. 不再用“公寓塔楼”表达升级

之前 Lv3 住宅会叠成 3 层平顶楼，和浮岛村落冲突。现在：

- 最高 **2 层**，且必须有坡屋顶；
- Lv2 长阁楼/老虎窗；
- Lv3 长**单层侧翼**，是横向加建，不是再加一层；
- 修掉了四坡屋顶陷入墙体的历史 bug（ConeGeometry 以中心为原点，需要上移半高）。

### 4. 移动端

桌面三岛同屏；竖屏只显示主岛，底部出现 **主岛 / 三叶 / 风铃** 切换。
点“三叶”会把镜头推到小岛，4 块田可以正常点击种植。

## 验证

- `npm test`：**186 通过 / 0 失败**（新增 10 条拓荒测试）
- `npm run typecheck` ✅
- `npm run build` ✅
- 存档重载后 `plots=20`、`world.plotTiles=20`，拓荒田块不丢。

## 坦白说

这仍然是 **程序化 low-poly** 的进程实验，不是 Township 的 2.5D 资产管线。
它解决的是“有限空间怎么继续玩”，不是“画风怎么达到 Township”。

如果这个方向对，下一步才是把两座小岛换成预制资产、把绳桥/码头/小岛地标做成真正的美术资产；如果方向不对，现在停损的成本也很低。
